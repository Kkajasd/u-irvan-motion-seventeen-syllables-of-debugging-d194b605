A program that writes one haiku about debugging — three lines in the
5-7-5 syllable shape, 73 characters total — to `/output/entry.txt`.

```
A null at midnight
the stack trace whispers my name
fix ships before dawn
```

Deterministic: no network, no randomness, no input. The same haiku on
every run. Built for the [Seventeen Syllables of Debugging](https://make.fun/c/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
bounty on make.fun.
